# 🚀 Quick Start

## 1. Clone Repository

```bash
git clone <your-repo-url>
cd predictplay-ai
```

---

## 2. Install Dependencies

```bash
npm install
```

---

## 3. Configure Environment Variables

Create `.env`

```env
GEMINI_API_KEY=your_gemini_api_key
CRIC_API_KEY=optional_cricket_api_key
APP_URL=http://localhost:3000
```

No Gemini key?

No problem.

PredictPlay AI automatically falls back to Demo Mode.

---

## 4. Run Development Server

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

---

## 5. Verify Types

```bash
npm run lint
```

# 🎮 Demo Mode Commands

### Start Match Simulator

```bash
curl -X POST http://localhost:3000/api/demo/start \
-H "Content-Type: application/json" \
-d '{"matchId":"mock_ipl_match"}'
```

### Stop Match Simulator

```bash
curl -X POST http://localhost:3000/api/demo/stop \
-H "Content-Type: application/json" \
-d '{"matchId":"mock_ipl_match"}'
```

### Generate AI Match Insight

```bash
curl -X POST http://localhost:3000/api/converse \
-H "Content-Type: application/json" \
-d '{"prompt":"Give me match insight for CSK vs GT"}'
```

---

# 🔌 API Endpoints

| Endpoint | Description |
|-----------|-------------|
| `/api/demo/start` | Start match simulator |
| `/api/demo/stop` | Stop simulator |
| `/api/converse` | Generate AI match conversation |
| `/api/coach` | Tactical coach mode |
| `/api/narrative` | Match storytelling |
| `/api/generate_prediction` | Prediction generation |
| `/api/generate_arcade` | Quiz & challenge generation |
| `/api/webhook` | Match event ingestion |
